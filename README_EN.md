# Sheet Pile Analysis Using the Finite Element Method

Software for analyzing sheet pile walls using the finite element method.

> 🇷🇺 [Russian version](README.md)

## How to use

1. Download the program release from the [Releases](../../releases) page.
2. Run the executable file `shpunt_final_elem.exe`.
3. Select the calculation scheme from the dropdown list.
4. Fill in all tabs on the left side with your parameters one by one. Alternatively, click **“Load parameters…”** if you have a ready file with filled parameters.
5. Click **“Calculate”** (or press `Enter` in any field).
